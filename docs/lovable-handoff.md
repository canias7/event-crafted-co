Have Lovable run their type regeneration against the current schema after the migrations below land. Once regen ships, you can drop most of the `(supabase as any)` casts (~25 files) — they'll surface compile errors on any wrong column names.

## 7. Hosting layer

- Front the dynamic sitemap function behind `/sitemap-live.xml` so robots.txt's second `Sitemap:` line resolves.
- Optional: set up Twitter / Facebook unfurls. Static index.html OG meta works for the homepage; per-page meta is dynamic via JS, so social bots that don't run JS only see the shell. Real solution is SSR or prerender behind a service worker.
- `npm install` needs `--legacy-peer-deps` because react-leaflet@5 has a strict peer of react@19 that conflicts with the project's react. The lockfile is committed with the working resolution.
